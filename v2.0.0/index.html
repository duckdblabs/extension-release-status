Next action legend — what does each one do?
Bump / Bump + drop X of Y patches

Moves duckdb's pinned commit for this extension forward to the commit found on its target branch. Any carried patch that has already landed there (X of the Y duckdb carries) is dropped in the same change.

python3 release/extensions/extension_util.py --current-base v1.5.6 --release-type major bump --make-pr
Drop X of Y patches

The pin doesn't move, but X of the Y patches duckdb carries for this extension have already landed there and can be dropped.

python3 release/extensions/extension_util.py --current-base v1.5.6 --release-type major bump --make-pr

Columns legend — commits, PRs and self-bumps
Commit

pinned → latest links to the GitHub compare view; +N is how many commits the pin is behind.

Self-bump

The result of the latest run of the extension's own BumpDuckDB workflow, for extensions that bump themselves. A dash means it doesn't.

Patch PR / Bump PR (on the extension's repo)

A Patch PR applies the patches duckdb carries to the extension's own branch, so duckdb can stop carrying them. A Bump PR only moves the extension's duckdb and extension-ci-tools submodules; it carries no patches. Neither is the duckdb/duckdb bump PR above, which moves duckdb's pin on the extension.

The dot is CI (passed, failed, pending); the word after the link is review state: draft, in review, changes requested or approved.
