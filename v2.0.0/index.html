How to read this page

Each extension has two independent states: Pin, whether duckdb/duckdb pins its latest commit, and Patches, whether duckdb carries patches for it. Hover, focus or tap any badge or next action in the table for this same text.

Pin

Behind

The extension has moved on since duckdb last pinned a commit.

ActionMove the pin. → Bump

Up to date

The pinned commit is the tip of the extension's target branch.

ActionNothing to do.

Patches

Broken

A carried patch no longer applies or reverses cleanly at the pinned commit, or a patch-failure issue is open.

ActionFix it on the extension's branch. → Apply patches

Carried

duckdb carries patches for this extension, and they all still apply.

ActionNone yet: bump drops any patch that has landed upstream.

None

duckdb carries no patches for this extension. Nothing to do.

Next actions

Bump / Bump + drop X of Y patches

Moves duckdb's pin to the latest commit on the target branch, dropping the X of Y carried patches that have landed there.

python3 -m release.extensions.extension_util --current-base v1.5.6 --release-type major bump --make-pr
Drop X of Y patches

The pin stays; X of the Y carried patches have landed upstream and can be dropped.

Same command as Bump.

Apply patches

Fix it on the extension's branch first; the failing patch is named under the label.

python3 -m release.extensions.extension_util --current-base v1.5.6 --release-type major patch --target <extension> --make-pr
Check patches by hand

The patches couldn't be checked (e.g. the clone failed); the reason is under the label. Rerun the status check, or check them by hand.

Wait for next commit

The tip doesn't build against this release, so the pin stays; the reason is under the label. The next commit on the target branch releases the hold.

None

Nothing to do.

Columns

bot extension duckdb

Who does the next action: the release bot on its next run, the extension's maintainers in their repo, or someone at duckdb by hand.

Details

Shows Target branch and Commit. pinned → latest opens the GitHub compare view; +N is how many commits the pin is behind.

Patch PR

On the extension's repo: applies duckdb's carried patches to its branch, so duckdb can stop carrying them.

Bump PR

On the extension's repo: moves its duckdb and extension-ci-tools submodules. Carries no patches.

Merge PR

On the extension's repo: merges the previous release line's bugfix branch into this one, so its fixes aren't lost. A "Merge-forward" issue means that merge hit conflicts and needs resolving by hand.

in #N

duckdb bump PR #N, shown in the status card, moves this extension's pin.

PR status

CI passed, failed, pending; grey on a draft · draft / changes requested / approved (no word: awaiting review). Landed PRs show as "merged" when none is open.

Needs a human: someone edited or commented, so the bot stops updating it.

by @x since 07-10-2026: someone else's PR, which the bot won't push over.
