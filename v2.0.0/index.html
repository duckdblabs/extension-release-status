Status legend — what do I have to do?
Up to date

The pinned commit matches the tip of the extension's target branch.

Maintainer action: Nothing to do.

Behind

The extension has moved since duckdb/duckdb last pinned a commit.

Maintainer action: Run with --generate-bump (add --make-pr to open the PR) to move the pin.

Has patches

duckdb/duckdb carries one or more patches for this extension.

Maintainer action: --generate-bump drops any patch already absorbed upstream on its own. One that isn't stays carried and needs no action here yet.

Blocked

Either a patch duckdb carries neither applies nor reverses cleanly at the pinned commit, or there's an open patch-failure issue for this extension -- either way, duckdb and the extension have diverged.

Maintainer action: Run with --generate-patches --target <extension> (add --make-pr) to open a PR resolving it on the extension side; it has to land there before duckdb can bump past it.

Next action legend — what does each one do?
BUMP (IN DUCKDB) TO ...

Moves duckdb's pinned commit for this extension forward to the commit found on its target branch. Any carried patch that has already landed there is dropped in the same change.

How: Run with --generate-bump (add --make-pr to open the PR).

REMOVE X OF Y PATCHES

The pin doesn't move, but X of the patches duckdb carries for this extension have already landed there and can be dropped.

How: Run with --generate-bump (add --make-pr to open the PR).

APPLY PATCHES (EXTENSION SIDE)

A patch duckdb carries no longer applies or reverses cleanly at the pinned commit -- it has to be resolved on the extension's own branch before duckdb can move past it.

How: Run with --generate-patches --target <extension> (add --make-pr).

NONE

Nothing for duckdb to change for this extension right now.

How: No action needed.
